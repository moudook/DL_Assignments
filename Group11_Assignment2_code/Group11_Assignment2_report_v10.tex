\begin{abstract}
This report presents the design, implementation, and empirical evaluation of Fully Connected Neural Networks (FCNNs) built from scratch using NumPy, trained with Stochastic Gradient Descent (SGD) and squared error loss. In strict accordance with the assignment rubric, we report: (1) class-wise precision, recall, F-measure, mean metrics, accuracy, and confusion matrices for every evaluated architecture on the validation set, and for the best architecture on the test set; (2) RMSE and \%RMSE on training and validation data for all architectures, and on test data for the best architecture; (3) split-wise (train/val/test) decision regions, model-fit plots, scatter plots, and activation surfaces for every hidden and output node of the best architecture; (4) comparison with the single-neuron perceptron from Assignment~1. On the LS dataset, 1HL$\times$2 achieves 100\% test accuracy. On the NLS dataset, 2HL $16\times8$ achieves 100\% test accuracy. Regression achieves test \%RMSE of 3.20\% (univariate) and 1.42\% (bivariate 1HL), demonstrating the FCNN\'s superiority over any linear model.
\end{abstract}

\subsection{Fully Connected Neural Network (FCNN)}
Our FCNN supports arbitrary multi-layer feedforward topologies. Forward propagation through layer $l$ is defined as:
\begin{equation}
\mathbf{z}^{(l)} = \mathbf{a}^{(l-1)}\mathbf{W}^{(l)} + \mathbf{b}^{(l)}, \quad \mathbf{a}^{(l)} = \phi^{(l)}(\mathbf{z}^{(l)})
\end{equation}
For \textbf{classification}: hidden layers use the sigmoid activation function $\sigma(z)=1/(1+e^{-z})$; the output layer uses a \textbf{softmax} function, producing a normalised probability distribution over the $K=3$ classes. 
For \textbf{regression}: hidden layers use the sigmoid activation; the output layer uses a \textbf{linear} (identity) activation function, i.e., $\phi^{(L)}(z) = z$. 
Weights are initialised from a normal distribution $\mathcal{N}(0,\,1/\sqrt{n_{\text{in}}})$, where $n_{\text{in}}$ is the number of inputs to the layer.

\subsection{SGD and Backpropagation}
Online Stochastic Gradient Descent (SGD) updates the network parameters after each individual training sample. The instantaneous squared error loss for a single sample is defined as:
\begin{equation}
\mathcal{L} = \frac{1}{K}\sum_{k=1}^{K}(\hat{y}_k - y_k)^2
\end{equation}
where $\hat{y}_k$ is the model's prediction and $y_k$ is the target.

During backpropagation, the error signal is propagated backwards. For the softmax output layer, the error signal is computed using the Jacobian of the softmax function. For sigmoid hidden units, the error signal for unit $j$ in layer $l$ is:
\begin{equation}
\delta^{(l)}_j = \left(\sum_k \delta^{(l+1)}_k w^{(l+1)}_{kj}\right) a^{(l)}_j (1 - a^{(l)}_j)
\end{equation}
where $w^{(l+1)}_{kj}$ is the weight connecting unit $j$ in layer $l$ to unit $k$ in layer $l+1$. The weights are updated via $\Delta w^{(l)}_{ji} = -\eta \, \delta^{(l)}_j a^{(l-1)}_i$.

\subsubsection*{Analysis and Inferences}
\begin{itemize}
    \item $2\times1$ achieves only 65.6\% validation accuracy; insufficient units cannot construct curved annular boundaries.
    \item $4\times2$ (89.7\%) partially separates classes but fails on Class~1 (middle ring).
    \item $8\times4$ achieves 99.7\% with 1 error; $16\times8$ achieves 100\% on both validation and test.
    \item The 2HL bottleneck ($h_1>h_2$) forces compressed representations in the second hidden layer, acting as a learned feature extractor over the non-linear basis from the first layer.
    \item All output softmax surfaces show near-binary activation fields: the correct class region approaches 1.0 and the rest approach 0.0.
\end{itemize}

\subsection{Inferences on Regression Results}
\begin{itemize}
    \item Both error curves show a steep initial decrease followed by a stable plateau, indicating rapid convergence.
    \item The model-output overlay plots confirm that the FCNNs accurately reproduce the underlying non-linear target functions.
    \item Scatter plots show predictions closely clustered along the perfect-fit diagonal across all splits.
    \item 1HL and 2HL achieve nearly identical test \%RMSE for the bivariate task ($\approx 1.4\%$), showing one well-sized hidden layer already captures the dominant non-linearity.
    \item Larger architectures do not consistently outperform smaller ones under online SGD with fixed epochs.
\end{itemize}

\section{Comparison and Inferences: Assignment 1 vs.\ Assignment 2}

\begin{enumerate}
    \item \textbf{Representational Failure Solved:} Single-layer perceptrons achieved 26.6\% on NLS (below chance) and RMSE reduced by $57\times$ on bivariate regression. FCNN hidden units construct localised non-linear basis functions that compose to form arbitrarily complex boundaries.
    \item \textbf{Bottleneck Configurations:} 2HL architectures with $h_1>h_2$ compress internal representations, achieving equivalent or better generalisation with fewer parameters in the second layer.
    \item \textbf{Softmax Output:} Produces a normalised probability distribution over classes, ensuring probabilities sum to 1 and providing well-calibrated class-specific confidence scores.
    \item \textbf{SGD vs.\ Batch GD:} Online SGD ($\eta=0.5$) introduces stochasticity that can escape shallow local minima, critical for the NLS non-linear landscape. Batch GD (A1, $\eta=0.01$) produced smooth curves but failed on NLS.
\end{enumerate}
