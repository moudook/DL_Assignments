XOR Neural Network — 3D View

Input Layer (not neurons):
Raw data: x1, x2, bias=1
These don't compute anything — just hand data forward.

Hidden Layer (2 neurons):
h1 = sigmoid(w11*x1 + w12*x2 + b1)
h2 = sigmoid(w21*x1 + w22*x2 + b2)
These COMPUTE new features from the input.

Output Layer (1 neuron):
yhat = sigmoid(v1*h1 + v2*h2 + b3)
This makes the final decision.

Total: 3 neurons (2 hidden + 1 output)
